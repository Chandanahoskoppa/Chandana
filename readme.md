# 📊 Unemployment Analysis with Python

This project analyzes unemployment trends in India using data from Kaggle. It includes:

- Time series visualization of unemployment by region
- Box plots comparing unemployment in urban vs rural areas
- Summary statistics for key economic indicators

## 📁 Dataset

Dataset sourced via `kagglehub`:
`gokulrajkmv/unemployment-in-india`

## 🚀 How to Run

```bash
pip install -r requirements.txt
python unemployment_analysis.py
